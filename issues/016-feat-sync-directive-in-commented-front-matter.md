# 016 (feat): 書き出し先の指定を、HTML のコメントで包んだ front matter にも書けるようにする

起票日: 2026-09-30

## 概要

issue 015 の `skip` を front matter の `metadata.esa-sync` に書くと、esa のプレビューに front matter（`---` と `metadata:` の行）が
本文として出る。esa の上だけで読む説明の記事（実例: `Users/jiikko/local` の `README`）では見せたくないので、
利用者は front matter を `<!--` と `-->` で包んで書いた。v0.4.0 では 1 行目が `---` でないため front matter として読まれず、
`skip` が効かなかった（015 の結果の側の注意「書き出さない指定らしい行がありますが、指定として効いていないため書き出します」が出て気づけた）。

```markdown
<!--
---
metadata:
  esa-sync: skip 
---
-->
```

## 仕様

- 本文の最初の空でない行が `<!--` だけ（前後の空白・BOM は許す）で、次の空でない行が `---` だけ（前後の空白は許す）のとき、「コメントで包んだ front matter」とみなす
- 次の `---` だけの行までを中身とし、その次の空でない行が `-->` だけなら閉じている（閉じの `---` より先に `-->` が来たものは閉じていない）。
  中身は front matter と同じ関数（`frontMatterTextDirective`）で読む
  （metadata の外のキー・`esa_sync`・文字列でない値・重複・読めない YAML の中の指定らしい行はエラー。エラーの文言は「コメントで包んだ front matter の …」）
- 閉じの `---` か `-->` が無いのに、中（閉じの無いときは front matter と同じく最初の空行まで）に指定らしい行（`firstSyncKeyLine`）があればエラー。無ければ普通のコメントとして何もしない
- 書けるのは `skip` だけ。パスはエラー（書き出したファイルではコメントの中なので front matter にならず、壊れた SKILL.md を黙って作るため）
- 末尾のコメントの指定と両方あればエラー。ただし両方 `skip` なら止めない（015 の「意味が同じなら止めない」と同じ）
- 本物の front matter（1 行目が `---`）とは同時に成り立たない（最初の空でない行が `<!--` と `---` のどちらか）

## 受け入れ条件

- [x] 実例の本文（`skip` の後ろの空白、前後の空行を含む）で書き出さない。repo の README.md は変わらず、注意も出ない
- [x] 包み方の崩れ（閉じの `---` / `-->` の欠け）と中身の書き損じはエラー
- [x] 普通のコメント（`---` で始まらない・1 行目がコメントの文）は今どおり
- [x] help と README に書いた
- [x] 変異で red を確認した

## 敵対的レビュー（2026-09-30、read-only のサブエージェント 1 体。issue の反証を兼ねる）

「書かないつもりの記事がエラーも注意も無く書き出される形」は、現実に起きうる揺れ（NBSP・CRLF・BOM・全角・ZWSP・`--＞`・`...` で閉じる・タブ・引用の中 等）では壊せなかった。

| 指摘 | 採否 | 対応 |
|---|---|---|
| P2 v0.4.0 の注意に従って末尾に `<!-- esa-sync: skip -->` を足し、包んだ方も残した記事が「2 つある」で止まる | 採用（再現） | 両方 skip なら止めない |
| P2 包んだ front matter のパスの指定が効くようになり、front matter の無い SKILL.md を黙って作る（016 前は記事名のパスへ書いていた） | 採用（再現） | 包んだ front matter に書けるのは skip だけにし、パスはエラー |
| P3 `<!--` と `---` の間の空行で包みとみなさない（閉じの側は空行を許していて非対称） | 採用 | 空行を許す |
| P3 閉じの無いときに本文の最後まで見る（front matter は最初の空行まで） | 採用 | 最初の空行までにそろえた |
| P3 包んだ中の散文が YAML として読めず、指定らしい行を含むと止まる | 記録のみ | 書き方が作為的 |
| P3 全角空白・NBSP で字下げした指定のエラーの文言が「metadata の外」になる | 記録のみ | 本物の front matter と同じ既存の挙動 |
| P3 包みとみなされない位置の `esa-sync: !!str skip` / `&a skip` に注意が出ない | 記録のみ | 作為的 |
| 仕様の書き方（`---` の前後の空白・`-->` が先に来た形・空行）と実装の食い違い | 採用 | 仕様を実装に合わせて書き直した |
| front matter（013）の文言・挙動の回帰 | 反証できなかった | — |

周回の打ち切り: 修正は受け付ける形を狭めるもの（skip だけ）と、既存の規則にそろえるもの（両方 skip・空行・最初の空行まで）で、
各修正をテストと変異で直接確かめたので、2 周目は回さない。
